# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue.

Open a private GitHub Security Advisory for this repository, or contact the
maintainer through the contact information on the repository profile. Include
as much detail as possible to reproduce the issue, including the affected
version, operating system, and a minimal proof of concept when safe to share.

Please do not include access tokens, private keys, passwords, or other secrets
in the report.

## Supported versions

Only the latest released version is currently supported with security fixes.
Users should upgrade to the latest release before reporting an issue.
